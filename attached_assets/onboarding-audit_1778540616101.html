3Bug #3
Generic CTA

4Bug #4
Empty State Without Direction

Feature Explanation Instead of Outcome

1Fix #1
Consequence-First Welcome
"Your first report is 3 clicks away." User knows exactly what happens next and why it matters.
2Fix #2
Progress With Reward
"Step 2 of 5 — after this, your dashboard is live." User knows the end reward before completing.
3Fix #3
Action-Named CTA
"Connect my first data source" instead of "Continue". Every button names the specific outcome.
4Fix #4
Empty State With Direction
"You're 1 import away from your first insight. Start here →" One clear next step, immediate quick win.
5Fix #5
Outcome-First Tooltips
"Your numbers update automatically — no manual refresh needed." What the user can do, not how it works.
6Fix #6
Quick Win Inserted Early

Microcopy Made Visible
